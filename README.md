# Font Fixer & Renamer Tool 🔠

![Version](https://img.shields.io/badge/version-2.0.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)

A powerful, intelligent tool to automatically clean, normalize, and format font names (folders and files). It handles complex typography naming conventions, extracts weights, fixes camelCase, and maps weights to standard numerical values (e.g., Bold -> 700).

## 🚀 Features
- **Smart Spacing:** Separates CamelCase and PascalCase names (e.g., `ArcTypeOutline` ➔ `Arc Type Outline`).
- **Weight Extraction:** Automatically identifies appended weights (e.g., `cascadeur-extrablackoblique` ➔ `Cascadeur 950 Oblique`).
- **Standard Numerical Mapping:** Converts typography text weights to standard CSS weights (Thin -> 100, Regular -> 400, Bold -> 700, ExtraBlack -> 950, etc.).
- **Symbol Cleaning:** Replaces hyphens and underscores with spaces.
- **Title Case Formatting:** Normalizes the case of all words.
- **Idempotent Execution:** Safely runs multiple times without double-renaming.

# ابزار اصلاح و نام‌گذاری فونت‌ها 🇮🇷

یک ابزار قدرتمند و هوشمند برای پاک‌سازی، استانداردسازی و فرمت‌بندی خودکار نام فونت‌ها (پوشه‌ها و فایل‌ها). این اسکریپت با الگوهای پیچیده‌ی نام‌گذاری تایپوگرافی سازگار است و می‌تواند وزن‌ها را استخراج کرده و به مقادیر استاندارد عددی تبدیل کند.

## 🚀 امکانات
- **فاصله‌گذاری هوشمند:** جداسازی کلمات به هم چسبیده (مانند `ArcTypeOutline` ➔ `Arc Type Outline`).
- **تشخیص و تفکیک وزن‌ها:** استخراج خودکار وزن‌های چسبیده به نام (مانند `cascadeur-extrablackoblique` ➔ `Cascadeur 950 Oblique`).
- **تبدیل به مقادیر عددی استاندارد:** تبدیل مقادیر متنی مثل Thin, Regular, Bold به اعداد معادل CSS یعنی 100, 400, 700, 950 و غیره.
- **پاک‌سازی علائم:** جایگزینی خط تیره و آندرلاین با فاصله.
- **بزرگ‌نویسی استاندارد (Title Case):** منظم‌سازی حروف اول کلمات.
- **اجرای امن (بدون تکرار):** عدم تغییر در فایل‌هایی که قبلاً اصلاح شده‌اند.

# ئامرازی چاککردن و ناونانی فۆنتەکان 🇹🇯 (کوردی سۆرانی)

ئامرازێکی بەهێز و زیرەک بۆ پاککردنەوە، ڕێکخستن و ستانداردکردنی ناوی فۆنتەکان (فۆڵدەر و فایلەکان) بە شێوەیەکی ئۆتۆماتیکی. ئەم سکریپتە دەتوانێت کێشی فۆنتەکان بناسێتەوە و بیانگۆڕێت بۆ ژمارەی ستاندارد.

## 🚀 تایبەتمەندییەکان
- **بۆشایی زیرەک:** جیاکردنەوەی وشە لکاوەکان (وەک `ArcTypeOutline` ➔ `Arc Type Outline`).
- **دەرکێشانی کێشی فۆنت:** ناسینەوەی ئۆتۆماتیکی کێشی لکاو بە ناوەکانەوە (وەک `cascadeur-extrablackoblique` ➔ `Cascadeur 950 Oblique`).
- **گۆڕین بۆ ژمارەی ستاندارد:** گۆڕینی کێشە دەقییەکان (وەک Bold, Regular) بۆ ژمارەی CSS (وەک 400, 700).
- **پاککردنەوەی هێماکان:** گۆڕینی هێڵی ناوەڕاست و ژێرەوە بۆ بۆشایی.
- **ڕێکخستنی پیتەکان (Title Case):** گەورەکردنی پیتی یەکەمی وشەکان.
- **جێبەجێکردنی سەلامەت:** پاراستنی ئەو فایلانەی کە پێشتر چاککراون.

# أداة إصلاح وتسمية الخطوط 🇸🇦

أداة قوية وذكية لتنظيف وتوحيد وتنسيق أسماء الخطوط تلقائيًا (المجلدات والملفات). تتعامل مع أنماط التسمية المعقدة في عالم الطباعة وتستخرج الأوزان وتحولها إلى قيم رقمية قياسية.

## 🚀 الميزات
- **تباعد ذكي:** فصل الكلمات المتصلة (مثل `ArcTypeOutline` ➔ `Arc Type Outline`).
- **استخراج الأوزان:** التعرف التلقائي على الأوزان الملتصقة (مثل `cascadeur-extrablackoblique` ➔ `Cascadeur 950 Oblique`).
- **التحويل الرقمي القياسي:** تحويل الأوزان النصية مثل Bold و Regular إلى قيم CSS القياسية (700، 400، 950، إلخ).
- **تنظيف الرموز:** استبدال الشرطات والشرطات السفلية بمسافات.
- **تنسيق حالة الأحرف (Title Case):** تكبير الحرف الأول من كل كلمة.
- **تنفيذ آمن:** عدم تكرار التسمية للملفات التي تم تعديلها مسبقاً.
